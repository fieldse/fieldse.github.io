Building this site in plain HTML

2026-11-10

This site is one HTML page per post, one stylesheet and a few small scripts. There is no framework, no bundler and no build step. Opening index.html in a browser is the whole dev setup.

Why plain

  • Nothing to upgrade. A static page from 2006 still renders today.
  • Nothing to break. No dependency tree means no surprise in it.
  • Fast. The whole site is smaller than most framework runtimes.

The terminal

The readout on the right is a <dl> in the HTML. With scripts off, that list is what you see. With scripts on, a small script hides it and replays it as a terminal session, one field at a time.

<dl>
  <dt>stack</dt><dd>go · python · typescript · bash</dd>
</dl>

Every command reads from the page itself. On the home page, ls log lists the log entries in the HTML, and cat about.md prints the bio paragraph. The data lives in one place.

Type help in the terminal to see what else it does.
